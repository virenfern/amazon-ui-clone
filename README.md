# amazon-ui-clone
Amazon Clone - UI Project
A responsive front-end clone of Amazon's homepage, built with pure HTML, CSS, and JavaScript. This project replicates the core UI elements and design of Amazon's e-commerce platform.
🎯 Project Overview
This project is a static replica of Amazon's user interface, created to practice and demonstrate front-end web development skills. It features a pixel-perfect recreation of Amazon's homepage including the navigation bar, product cards, and footer sections.
✨ Features

Navigation Bar: Fully styled header with logo, location selector, search bar, and user options
Search Functionality UI: Dropdown category selector and search input field
Product Categories: 8 product category cards with hover effects
Hero Section: Banner with promotional message
Responsive Design: Adapts to different screen sizes
Interactive Elements: Hover effects on navigation items and buttons
Footer Section: "Back to Top" button and informational links
